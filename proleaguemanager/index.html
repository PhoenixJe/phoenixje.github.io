3.1 참가자

리그에 참가할 참가자를 테란·토스·저그 종족별로 등록합니다.

1

종족 라벨

테란·토스·저그 중 참가자 목록을 수정할 종족을 선택합니다.

2

참가자 입력 영역

선택한 종족의 참가자 이름이 표시됩니다.

참가자 입력

테란·토스·저그의 종족 이름을 클릭하면 해당 종족의 참가자 목록을 수정할 수 있습니다. 예를 들어 테란을 클릭하면 테란 참가자 전체를, 토스를 클릭하면 토스 참가자 전체를 수정합니다.

참가자 이름은 띄어쓰기로 구분하여 입력합니다. 편집 화면을 열면 입력 위치가 기존 목록의 맨 끝에 자동으로 놓이므로, 기존 참가자를 지우지 않고 이어서 새로운 참가자를 추가할 수 있습니다.

입력 방법 보기

종족별 참가자를 입력하고 기존 목록에 참가자를 추가하는 과정을 확인할 수 있습니다.

3.2 팀선정

등록한 참가자를 1팀과 2팀으로 배정합니다.

1

팀 라벨

참가자를 배정할 1팀 또는 2팀을 선택합니다.

2

팀별 참가자 목록

각 팀에 배정된 참가자가 표시되는 영역입니다.

팀 선정 방법

등록한 참가자를 1팀과 2팀으로 배정하는 방법은 두 가지입니다. 두 방법 중 편한 방식을 사용하면 됩니다.

참가자 → 팀

옮길 참가자를 마우스 왼쪽 버튼으로 클릭한 다음 1팀 또는 2팀을 클릭합니다.

팀 → 참가자

1팀 또는 2팀을 먼저 클릭한 다음 해당 팀으로 옮길 참가자를 클릭합니다.

선택 상태

참가자 이름이나 팀 이름 위에 마우스를 올리면 선택할 수 있는 항목임을 알 수 있도록 테두리가 강조됩니다. 클릭하면 테두리가 더 진하게 표시되며 선택 상태가 유지됩니다.

선택을 취소하려면 선택한 항목을 마우스 왼쪽 버튼으로 한 번 더 클릭합니다. 참가자를 선택했다면 같은 참가자를 다시 클릭하고, 팀을 선택했다면 같은 팀을 다시 클릭하면 됩니다.

이미 팀에 배정된 참가자는 참가자 목록에서 회색으로 흐리게 표시됩니다. 따라서 아직 팀이 정해지지 않은 참가자를 쉽게 확인할 수 있습니다.

팀 배정 취소

팀에 잘못 배정한 참가자는 팀선정 영역에서 해당 참가자를 마우스 오른쪽 버튼으로 클릭하면 배정을 취소할 수 있습니다.

3.3 맵

맵 구성

1

라벨 영역

사용맵·1세트·2세트 중 수정할 항목을 선택합니다.

2

맵 목록 / 맵 순서 영역

리그에서 사용할 맵 목록과 각 세트의 맵 순서가 표시됩니다.

3

버튼 영역

맵 목록이나 맵 순서를 복사하거나, 핀볼 결과를 1세트 또는 2세트에 불러올 수 있습니다.

기본 사용

핀볼 결과를 결과 버튼으로 불러오면 해당 세트의 맵 순서가 자동으로 입력됩니다. 입력된 맵 순서는 복사 버튼으로 복사할 수 있습니다.

추가 입력

사용맵 수보다 많은 맵 순서가 필요한 경우에는 핀볼을 한 번 더 진행합니다. 첫 번째 핀볼 결과는 결과 버튼으로 불러오고, 추가 추첨에서 필요한 맵만 1세트 또는 2세트를 클릭해 뒤에 직접 입력합니다.

예를 들어 사용맵이 7개인 9판 5선에서는 두 번째 핀볼 결과의 1·2위 맵을 추가합니다. 편집 시 커서는 기존 맵 순서의 맨 뒤에 위치하며, 완성된 맵 순서는 복사 버튼으로 복사할 수 있습니다.

핀볼 배치

핀볼은 화면 크기에 따라 배치 형태가 달라지며, 두 화면 모두 추첨 후 맵 영역의 결과 버튼을 바로 사용할 수 있도록 배치됩니다.

기본창

핀볼이 가로형으로 맵 영역 위쪽에 배치됩니다.

최대화

핀볼이 세로형으로 오른쪽에 배치되어 맵 영역과 나란히 표시됩니다.

3.4 펀딩

펀딩 구성

1

입력 영역

후원자 닉네임과 펀딩 개수를 입력합니다.

2

두당 개수

등록된 참가자 수를 기준으로 각 펀딩의 두당 개수가 자동으로 계산되어 표시됩니다.

3

합계 영역

입력된 내역의 총 펀딩 개수와 두당 개수 합계를 표시합니다.

두당 개수 자동 계산

등록된 참가자 수에 따라 3:3부터 6:6까지의 경기 구성을 자동으로 판단하고, 해당 팀 인원수를 기준으로 두당 개수를 계산합니다.

경기 인원을 판단할 수 없는 경우에는 미확정으로 표시됩니다.

영상에서는 참가자를 10명에서 9명, 8명으로 변경하며 두당 개수가 자동으로 바뀌는 과정을 보여줍니다.

행 자동 추가

마지막 입력 행에 내용을 입력하면 다음 빈 행이 자동으로 추가됩니다.

행이 표시 영역을 넘어가면 스크롤바가 생성되어 추가된 내역을 계속 확인할 수 있습니다.

모드별 표시

펀딩 기능은 진행자 모드와 참가자 모드에서 동일하게 동작합니다.

참가자 모드에서는 왼쪽 상단에 크게 표시되며, 진행자 모드에서는 오른쪽 하단에 축소된 형태로 표시됩니다.

합계는 참가자 모드에서는 테이블 아래에 파란 글씨로, 진행자 모드에서는 테이블의 합계 행으로 표시됩니다.

3.5 하단 기능 버튼

1저장

현재 프로그램에 입력된 내용을 TXT 파일로 내 문서\Proleague Manager 폴더에 저장합니다.

프로그램의 입력 내용은 자동으로 유지되므로, 이 버튼은 프로그램 상태를 저장하는 기능이 아닙니다.

2리셋

현재 프로그램에 입력된 내용을 초기화합니다.

3핀볼

핀볼 창을 실행합니다.

핀볼 창의 기본창과 최대화 화면은 3.3 맵에서 확인할 수 있습니다.

4룰렛

네이버 룰렛을 엽니다.

5타이머

네이버 타이머를 엽니다.

6Elo

Eloboard 사이트를 엽니다.

7정산

모드 선택에서 설정한 사용자명을 기준으로 정산 내용을 구성하고, 확인한 내용을 바탕으로 정산 결과를 계산합니다.

정산 확인

정산 버튼을 누르면 설정한 사용자와 같은 팀 참가자의 정보를 불러와 정산할 내용을 확인할 수 있습니다.

진행자 모드

진행자 모드에서는 설정한 사용자의 펀딩 개수와 같은 팀 참가자의 이름·펀딩 개수가 자동으로 입력됩니다.

참가자 모드

참가자 모드에서는 설정한 사용자의 펀딩 개수와 같은 팀 참가자의 이름이 자동으로 입력되며, 팀원들의 펀딩 개수만 직접 입력하면 됩니다.

정산 결과

정산 확인창에서 결과 버튼을 누르면 받을 금액과 보낼 금액이 자동으로 계산되어 영수증 형태로 표시됩니다.
